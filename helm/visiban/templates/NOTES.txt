Visiban has been deployed!

1. Get the application URL:
{{- if .Values.ingress.enabled }}
  http{{ if .Values.ingress.tls.enabled }}s{{ end }}://{{ .Values.ingress.host }}
{{- else }}
  export POD=$(kubectl get pods -l "{{ include "visiban.frontend.selectorLabels" . }}" -o jsonpath="{.items[0].metadata.name}")
  kubectl port-forward $POD 8080:80
  # Then open http://localhost:8080
{{- end }}

2. Backend API is available under /api/ (proxied through the frontend Nginx).

3. Run database migrations (handled automatically by an init container on every deploy).

IMPORTANT: Change the default secret values before going to production:
  --set secret.djangoSecretKey=<strong-random-key>
  --set postgresql.auth.password=<strong-password>
