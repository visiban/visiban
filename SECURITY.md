# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Visiban, please report it responsibly.

**Do not open a public issue.** Instead, email security@visiban.com with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 48 hours and aim to provide a fix within 7 days for critical issues.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Security Updates

Security fixes are released as patch versions (e.g., 1.0.1) and announced in the [CHANGELOG](CHANGELOG.md).
