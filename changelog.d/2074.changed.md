Changed: the opt-in Compose `scheduler` service now runs `prune_board_events` daily at 03:00 UTC by default (`SCHEDULE_PRUNE_BOARD_EVENTS`, previously `off`), so board change-feed events, which keep card payloads after a card or board is deleted, no longer accumulate forever. Events older than `BOARD_EVENT_RETENTION_DAYS` (default 30) are deleted. Set `SCHEDULE_PRUNE_BOARD_EVENTS=off` to opt out. Helm is unchanged.
