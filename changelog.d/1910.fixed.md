Helm: `postgresql.auth.existingSecret` now also supplies the backend's database password. The chart sets a new optional `DATABASE_URL_PASSWORD` environment variable from that Secret's `password` key and renders `database-url` without a password; the backend percent-encodes the password into `DATABASE_URL`. Previously the backend URL was built from `postgresql.auth.password`, which could differ from the Secret PostgreSQL started with. `postgresql.auth.password` is no longer required (or checked against the placeholder) when `postgresql.auth.existingSecret` is set. Installs that do not set it, and installs that set `secret.existingSecret`, render unchanged (#1910).
