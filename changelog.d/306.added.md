Site admins can now configure outbound email (SMTP) from **Admin → Settings → Email** instead of environment variables, with a **Send test email** button that delivers to the admin's own address and reports a specific reason on failure. The SMTP password is encrypted at rest. Existing installs are unaffected: environment variables remain the default source and are used until an admin explicitly switches over, and setting `EMAIL_BACKEND` explicitly continues to override everything. Adds the `EMAIL_USE_SSL` and `EMAIL_TIMEOUT` environment variables, plus an optional `VISIBAN_SECRET_ENCRYPTION_KEY` for installs that rotate `DJANGO_SECRET_KEY`. The `DEFAULT_FROM_EMAIL` placeholder check moved from startup to send time, so a fresh production instance now boots and can be configured entirely through the UI.
