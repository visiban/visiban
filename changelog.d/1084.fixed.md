Restored `linux/arm64` container image publishing on release tags, alongside `linux/amd64`. `:<tag>`, `:latest`, and (for stable releases) the `:MAJOR.MINOR` alias are multi-arch manifest lists on both the GitLab registry and GHCR again. arm64 publishing had regressed silently since 2026-06-26 and was dropped from the release pipeline entirely when the amd64 push jobs moved to kaniko (#1084). If the arm64 build ever fails on a release tag, the amd64-only image is never published under the real tag names — the pipeline fails loudly instead of silently shipping a single-arch image under a multi-arch tag. The on-demand manual GHCR push jobs, which had no such safeguard, were removed.
