Fixed: deleting a user in the Django admin, from the delete page or the **Delete selected users** action, now updates connected clients live. Each card that carried a reference to the user (creator, assignee, comment author, checklist creator, attachment uploader) gets a `card.updated` frame, and every board and group the user was a member of gets a `member.removed` frame, so open boards and group pages no longer show the deleted user until a reload.
