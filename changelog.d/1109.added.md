WebSocket connections can now be authenticated with a short-lived ticket, so clients that authenticate to the REST API with a token — native, CLI, and front ends served from another origin — receive live board and group updates instead of being closed with `4001`. Call `POST /api/v1/auth/ws-ticket/` with any supported credential and pass the returned value as `?ticket=` on the upgrade. Tickets are single-use, expire after 30 seconds, and are stored hashed; they authenticate only, so board and group membership is still enforced on every connection. The browser SPA's session-cookie handshake is unchanged (#1109).
