- Fixed the OpenAPI schema understating nullability of `assignee` and `created_by` on the cross-board card query endpoint (`GET /api/v1/cards/`). Both are nullable foreign keys on `Card` — an unassigned card, or one whose creator was since deleted, has always returned `null` for these fields — but `CardQuerySerializer` declared them without `allow_null=True`, so the published schema described them as always present objects.
