Release images are now verifiable, not just the Helm chart: every `backend` and `frontend` image on both `ghcr.io/visiban/visiban` and `registry.gitlab.com/visiban/visiban` is cosign-signed by the release pipeline, and each architecture (`linux/amd64`, `linux/arm64`) carries its own cosign-attested CycloneDX SBOM. See "Verifying release images" in the administration docs for the `cosign verify` and `cosign verify-attestation` commands.
