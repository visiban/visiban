Released `backend` and `frontend` images are now cosign-signed (keyless, by the release pipeline) and carry a cosign-attested CycloneDX SBOM per architecture (`linux/amd64` and `linux/arm64`), on both `ghcr.io/visiban/visiban` and `registry.gitlab.com/visiban/visiban`, so you can verify the images the Helm chart pulls, not just the chart. See "Verifying release images" in the administration docs for the `cosign verify` / `cosign verify-attestation` commands.
