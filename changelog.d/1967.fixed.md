Board sharing: when a public share link is enabled, rotated or revoked, or turned off automatically because the admin who enabled it lost admin rights, other board admins now see the change without a reload, including in a **Sharing** tab they already have open. Before, the `board.updated` event these changes send could not carry the share state, so an open Sharing tab kept showing a revoked link as active. A new additive WebSocket event, `share_link.updated` (`{board_uid, active, expires_at}`), is sent to board admin and site admin sockets only, and its change-feed rows are returned to those readers only. It never carries the token. `board.updated` is still sent as before (#1967)
