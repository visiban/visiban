Board sharing: when a public share link is enabled, rotated or revoked, has its expiry changed in the Django admin, or is turned off automatically because the admin who enabled it lost admin rights, other board admins now see the change without a reload, including in a **Sharing** tab they already have open. Before, the `board.updated` event these changes send could not carry the share state, so an open Sharing tab kept showing a revoked link as active. If the tab is still showing a one-time link that was then revoked or rotated elsewhere, it removes that link, says why, and keeps keyboard focus on the tab. A new additive WebSocket event, `share_link.updated` (`{board_uid, active, expires_at, issued_at}`), is sent to board admin and site admin sockets only, and its change-feed rows are returned to those readers only, with no actor. It never carries the token. `issued_at` marks the frame of an enable or rotate, and the share action response gains the matching additive `share_token_issued_at` field. `board.updated` is still sent as before (#1967)
