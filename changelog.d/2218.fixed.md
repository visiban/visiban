Date custom-field values are now stored as `YYYY-MM-DD` whichever spelling of the same day was sent (`20260105`, `2026-1-5`, `2026-W02-1`), and number values with digit-group underscores or non-ASCII digits are stored as plain digits (`1_000` becomes `1000`), so threshold marks apply to every value. A data migration rewrites values stored by earlier versions (#2218).
