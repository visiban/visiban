A JSON or urlencoded request body over 2.5 MB, and a query string with more than 1000 parameters, now answer a JSON `400` (`{"detail": "..."}`) instead of an HTML error page, through a project-wide DRF exception handler. Django's `django.security.*` log line is kept. Because the query-string case can occur on any operation, documenting the `400` on every operation in the OpenAPI schema is tracked in #2140.
