Board admins can now give a single swimlane its own health status (On track, At risk or Off track) from the lane's label panel. A lane's status is independent of the board's: it never inherits from the board and never rolls up to it. It updates live for everyone with the board open, round-trips through JSON export and import, and is exposed as `health_status` on the swimlane API, the `swimlane.updated` event and the MCP `list_swimlanes` tool. Migration `boards/0102` adds one nullable column with no index (#2243).
