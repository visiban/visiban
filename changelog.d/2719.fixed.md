Add child and the Rules page's default child board select no longer hide a board you can add cards to without saying why: a board with no swimlane, no columns, or a first column that doesn't allow new cards now stays in the select as a greyed-out, unselectable option with what to fix (for example "Add a swimlane first"), and Add child lists them when no board can be picked. The `child-board-options` and `default-child-board-options` responses carry a new `unavailable` list of `{id, name, reason}` (#2719).
