Add child and the Rules page's default child board select no longer hide a board you can add cards to without saying why: a board with no swimlane, no columns, or a first column that doesn't allow new cards is now named under the select with what to fix (for example "add a swimlane first"). The `child-board-options` and `default-child-board-options` responses carry a new `unavailable` list of `{id, name, reason}` (#2719).
