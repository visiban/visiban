A `color` on a column, swimlane, label, or group label must now be hex (`#RRGGBB`, or `#RGB`, which is stored expanded); a name such as `red` or a malformed value is a `400` on create and update. A color you resend unchanged is still accepted, so rows saved before this release keep loading and renaming. A JSON board import no longer fails on a non-hex color: it uses the default and counts it in `import_summary.skipped.colors` (#2093).
