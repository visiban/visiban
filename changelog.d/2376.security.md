A card now holds at most 1000 comments and 500 checklist items, so one member or a leaked API token can no longer grow a single card without bound. A create past a cap gets `400` with `code` `comment_quota_exceeded` or `checklist_quota_exceeded`, nothing is stored, and the card detail panel shows the reason. The caps are checked under the card row lock, so two creates racing for the last slot cannot both succeed. Set `COMMENT_MAX_PER_CARD` / `CHECKLIST_MAX_ITEMS_PER_CARD` (Helm: `backend.settings.commentMaxPerCard`, `checklistMaxItemsPerCard`) to change them; `0` turns a cap off (#2376).
