Cards can now link to a pull request or merge request (GitHub, GitLab, or any other http/https URL). The link appears as a small badge on the card face that opens it in a new tab, and is set, edited, or removed from a new "Pull / merge request" section in the card detail panel — pasting a GitHub PR or GitLab MR URL fills in the provider and reference automatically. It is also available on the REST API as the card's `external_ref` field (`{provider, ref, url}`), carried in real-time updates and JSON board export/import, and deliberately left off public share links (#352).
