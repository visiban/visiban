User settings (`/settings`) now use the shared Settings layout: Account (Profile, Security, Access tokens), Preferences (Notifications, Appearance, Behavior) and Visiban (About) sections, with Find a setting and a section menu on phones. Profile saves from a sticky Save bar, Notifications use In-app and Email columns, and choosing the `mcp:write` scope now turns on and locks `mcp:read`. Existing `?tab=` deep links keep working.
