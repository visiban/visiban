Board view: the column header row, every swimlane and every collapsed swimlane now share one column grid, so columns line up in every row. Columns split the board's width equally with 8 px between them; below 1240 px of board width (or about 160 px per column on a board with many columns) the grid scrolls sideways inside its own box. Columns can no longer be resized by dragging their edge; the separator still inserts a column on click (#2300).
