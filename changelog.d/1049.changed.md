- Replaced Redis with [Valkey](https://valkey.io) — the BSD-3, Linux Foundation fork of Redis — as the Channels (WebSocket) and cache backend across Docker Compose (dev and production), CI, and the Helm chart (now using the `bitnami/valkey` subchart; in-cluster service is `<release>-valkey-primary`). Valkey is wire-compatible with Redis 7, so the `redis://` URL scheme and the `REDIS_URL`, `REDIS_CACHE_URL`, `REDIS_PASSWORD`, and `REDIS_PORT` environment variables are unchanged. The store holds only ephemeral channel-layer and cache data, so no data migration is required — see the upgrade guide.
