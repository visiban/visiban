An expired previous webhook signing secret is now deleted by three paths, not only the webhook dispatcher: a board admin's request to that board's webhook endpoints (`status` included) and a new daily `sweep_webhook_secrets` scheduled job (Compose `SCHEDULE_SWEEP_WEBHOOK_SECRETS`, default 04:00 UTC; Helm `scheduledJobs.sweepWebhookSecrets`, on once `scheduledJobs.enabled` is). An install that runs none of the three still keeps the expired ciphertext stored. It was never used to sign after expiry either way (#2119).
