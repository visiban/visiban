MCP (Model Context Protocol) server — connect Claude, Copilot, or any MCP-compatible AI agent to Visiban and let it read your boards. The server is served at `/mcp` over the Streamable HTTP transport and authenticates with an existing Personal Access Token sent as `Authorization: Bearer <token>`. This first release ships one tool, `list_boards`, which returns every board the token's owner can access along with their effective role and column, swimlane, and card counts. Off by default; operators enable it with `MCP_SERVER_ENABLED=true`.
