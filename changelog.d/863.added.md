Outbound webhooks: board admins can register URLs that receive a signed `POST` (`X-Visiban-Signature`, HMAC-SHA256 over the timestamp and body) for each board change-feed event, delivered in order with retry and automatic turn-off, from the new **Board settings → Webhooks** tab or `/api/v1/boards/{id}/webhooks/`. Off by default: operators set `WEBHOOKS_ENABLED=true` and run the dispatcher (`manage.py dispatch_webhooks`, the Compose `webhooks` profile, or Helm `webhooks.dispatcher.enabled`). Destinations must be public `https` addresses unless listed in the new `WEBHOOK_ALLOWED_PRIVATE_TARGETS`. Board admins get a `webhook_disabled` notification and email when a webhook turns off. Adds the `BOARD_EVENT_HOOKS` extension point (#863).
