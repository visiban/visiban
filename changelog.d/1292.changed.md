**Behavior change:** `PATCH` on a checklist item that changes `position` now returns `400 Bad Request` instead of silently applying it — the same class of bug as #1275 for cards/columns/swimlanes. A plain PATCH bypassed the reorder broadcast that only the new dedicated endpoint evaluates. Use `POST .../cards/{id}/checklist/reorder/` to reorder checklist items instead. A request that echoes the current `position` back unchanged (e.g. a full-object round-trip) is still accepted. (#1292)
