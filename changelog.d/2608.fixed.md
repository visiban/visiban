Unlinking or linking a card's parent, and saving or removing a card's pull or merge request link, now moves keyboard focus to the next control in the same update that removes the button you pressed, so focus no longer sits on the page body for a moment, where a screen reader could announce it. The same applies to unlinking a child card, revoking an invite, moving a card anyway past a limit from the card peek, a forced move that a hard limit then refuses (card detail and card peek), turning a webhook back on, and loading the last page of subgroup boards.
