The card move endpoint now checks the caller's role before the shape of the request body, so a viewer or collaborator who sends a body that is not a JSON object gets `403` instead of `400`, matching card create (#2191); a caller without board access still gets `404` (#2225). The group transfer-ownership endpoint (`POST /api/v1/groups/{id}/transfer-ownership/`) follows the same order: a non-owner now gets `403` and a caller with no access `404` before a non-object body can get `400`.
