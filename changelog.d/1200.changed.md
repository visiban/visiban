- Helm: the bundled Valkey now runs as the chart's own StatefulSet on the official, pinned `valkey/valkey:8-alpine` image (the same major as `docker-compose.prod.yml`) instead of the Bitnami `valkey` subchart, whose default image was the floating `bitnami/valkey:latest`. That tag meant a Helm install could switch Valkey major on any pod reschedule with no diff (it was Valkey 9 while Compose ran 8). The pod runs as a non-root user with a read-only root filesystem and no capabilities. The `<release>-valkey-primary` Service name and the backend's `REDIS_URL` / `REDIS_CACHE_URL` are unchanged. `helm upgrade` replaces the Valkey pod, which holds only rebuildable real-time and cache data, and fails with an explanation if the values still set `valkey.architecture=replication`, `valkey.auth.enabled=true`, or a Bitnami image. `scripts/helm-structure-check.sh` now fails any rendered image that is untagged or tagged `latest`. Chart version 0.5.0. See the upgrade guide.
