`PATCH /api/v1/groups/<id>/board-defaults/` returned an unhandled 500 instead of a 400 when the request body was valid JSON but not a JSON object (a bare number, string, array, `null` or bool). It now returns `400 {"detail": "Request body must be a JSON object."}`, matching the guard already applied to card move, group ownership transfer, and saved-filter creation.
