Added two CI gates, `rbac-coverage` (`scripts/check-rbac-coverage.py`) and `broadcast-deferral` (`scripts/check-broadcast-deferral.py`), which assert statically what the `rbac-check` and `broadcast-check` agent gates previously asserted by reading each diff. `rbac-coverage` checks that every board/group-scoped endpoint has an authentication gate, resolves the caller's role through the shared resolver rather than a raw membership lookup, applies a minimum-role check on every write action, and scopes board-child lookups so a global pk cannot cross boards. `broadcast-deferral` checks that every such write reaches a broadcast, that every raw `broadcast_*_event()` sits inside a `transaction.on_commit()` callable, that no commit hook holds an ORM row read from the enclosing scope, and that no emit call sits in a loop over rows of one channel. Both run in the `test` stage with `needs: []` in well under a second, both ship a `--self-test` per the #1093 house rule, and both distinguish "unhandled pattern — hand it to the agent" (exit 3) from a pass, so a view whose authorization cannot be read statically fails the pipeline instead of passing silently. Recorded exceptions live in self-invalidating tables in each script. No application behavior changed. See `docs/development/rbac-and-broadcast-gates.md` (#1143).
