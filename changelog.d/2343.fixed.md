Fixed three accessibility gaps on the board. The column header actions kebab is now visible on touch devices that have no hover (#2343). The `e` shortcut, the collapsed-lanes "Expand all swimlanes" button, and the View menu column Hide all / Show all now announce the new lane and column state to screen readers (#2338). The inline Confirm/Cancel prompts (comment delete, member and invite revoke, webhook confirms, policy row switch) no longer wrap the question in a second live region, so the persistent announcer reads each prompt once and a failure message no longer re-reads it (#2232).
