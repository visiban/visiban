On an invite-only instance, an invite a group admin emails (#731) now also lets a newcomer create an account — by password or OAuth — and joins them to the group with the invite's role. The invite is consumed by the registration itself, so it can create only one account. Shareable group links still only work for people who already have an account, and a closed instance still creates no accounts. The group panel's "New users can't sign up on this site" warning now shows only on closed instances. (#1445)
