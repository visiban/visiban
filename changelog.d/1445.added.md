On an invite-only instance, a group invite that a site admin emails (#731) now also lets a newcomer create an account — by password or OAuth — and joins them to the group with the invite's role. The registration itself uses up the invite, so it creates one account (strictly for password sign-up; best-effort for OAuth, as with site invites). The invite stops creating accounts if its sender is deactivated, stops being a site admin or group admin, or if email invites are turned off. Emailed invites from group admins who are not site admins, and shareable group links, still only work for people who already have an account, and a closed instance still creates no accounts. The group panel's "New users can't sign up on this site" warning now reflects this. (#1445)
