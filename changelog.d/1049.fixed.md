- Fixed real-time board updates silently stopping on connections idle for more than 5 seconds. `backend/requirements.txt` left the `redis-py` client unpinned, so fresh installs pulled redis-py 8.0.0, which enforces a 5-second socket read timeout on the block-forever `BZPOPMIN` that `channels-redis` uses in its receive loop — killing every idle WebSocket. `redis-py` is now pinned to `>=4.6,<6`.
