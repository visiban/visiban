Parent cards' child progress now refreshes live after column changes on the child board, and Django-admin edits refresh linked cards live. Toggling a child-board column's "done" flag, reordering columns so a different column comes first, or deleting the first column, sends one new, additive `card.children_bulk_changed` event (`{parent_ids}`, ids only, or `{parent_ids: [], reload: true}` above 100 parents) to each affected parent board, through the API and the Django admin alike; `card.children_changed` keeps its shape. A card edit in the Django admin that moves a child card to another column, archives it or restores it updates its parent card's child progress (`card.children_changed`), and a Django-admin rename of a parent card's board, column or swimlane updates the parent shown on its children (`card.parent_changed`, the same bounded event the API rename sends since #2416). Before, these changes showed only after a reload.
