Django-admin edits now refresh linked cards live: a card edit in the Django admin that moves a child card to another column, archives it or restores it updates its parent card's child progress (`card.children_changed`), and a Django-admin rename of a parent card's board, column or swimlane updates the parent shown on its children (`card.parent_changed`, the same bounded event the API rename sends since #2416). Before, these changes showed only after a reload.
