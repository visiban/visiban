Issue Board Lens outbound-call observability for site admins: every GitHub/GitLab API call the lens makes is now counted (per provider, resource kind and outcome) and written as one structured `git_lens.outbound` log line with no tokens or query values. The new admin-only `GET /api/v1/admin/git-lens/usage/` endpoint reports the last 24 hours of counts, cache hit/miss outcomes, and the fixed limits that bound the traffic. Only available with `GIT_LENS_ENABLED=true`; log verbosity is set with the new optional `GIT_LENS_OUTBOUND_LOG_LEVEL` (default `INFO`) (#1061).
