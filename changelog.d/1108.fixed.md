- Fixed the OpenAPI schema (`/api/schema/`) misdescribing the `move`, `comments`, `checklist`, column/swimlane `reorder`, `share`, and `members` custom actions — these previously fell back to the viewset's default serializer and documented the wrong request/response shape (e.g. `move` appeared to accept/return a full `Card` object instead of its real `{column_id, swimlane_id, position, version}` request and `{card, movement}` response, including its `version_conflict` / WIP / weight-limit error bodies). Also fixed related nullable-field gaps in `CardSerializer` and `CardMovementSerializer` (`assignee`, `moved_by`, `last_moved_at`, and several `SerializerMethodField`s) that a schema-vs-response contract test for `move` surfaced. A client generated from the schema (e.g. the MCP REST-client package, or any other external consumer) now gets accurate types for these endpoints.
