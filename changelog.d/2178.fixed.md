The OpenAPI document now describes the `400` responses the API already returns on operations that declare their own `400`: each declared schema is widened with `anyOf` to also accept the `{"detail": ...}` body of a parse, charset or server-limit error and, on every operation except a `GET` without a request body, the field-keyed refusal of a lone surrogate, so those responses no longer violate the published contract. A `400` declared with a description only gains the generic validation-error body.
