Card urgency now uses flag icons instead of the ⚑/⏱ text characters, so they take the status color on every platform and read correctly to screen readers (the overdue checklist-item count on the card face uses the same flag icon; an overdue status announces "Overdue"). An overdue status line is danger-toned with a flag icon, and a due-soon status line is secondary text with a flag icon; the standalone due-date pill appears only when no Overdue or Due soon status carries the date. On non-compact cards the urgency badge now only shows the calm "Just moved" cue.
