The issue board lens now caps how often one member can force an upstream re-fetch with the Refresh button (a 30-second floor per person, per board). Refresh bypasses the shared 60-second cache on purpose so you get the latest issues, but nothing previously bounded how often it could be used — a single member holding down Refresh could drive continuous calls to GitHub/GitLab and burn the shared API rate limit for everyone viewing that repo. Refresh stays available to every board role, viewers included; only the rate is capped, and a click inside the cooldown quietly serves the cached board instead of failing.
