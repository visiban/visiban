Added an opt-in PostgreSQL connection pool, enabled with `DATABASE_POOL=true` (sizes via `DATABASE_POOL_MIN_SIZE` and `DATABASE_POOL_MAX_SIZE`; Helm: `backend.settings.dbPool`). It is off by default, so existing installs keep per-request connections. This adds the `psycopg-pool` dependency (LGPL-3.0, via `psycopg[pool]`). The scaling guide no longer claims persistent per-worker connections.
