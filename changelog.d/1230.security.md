The Helm chart no longer appends `127.0.0.1,localhost` to `ALLOWED_HOSTS`. Behind the frontend's catch-all nginx, which forwards the client `Host` header, that let any client reaching the frontend Service directly send `Host: localhost` and bypass the host pin (Host-header poisoning of absolute URLs such as password-reset links). The chart's probes and helm tests now send the first configured host instead. Installs that rely on `localhost` (for example `kubectl port-forward`) must add it to `backend.settings.allowedHosts`; see the 1.2 upgrade notes.
