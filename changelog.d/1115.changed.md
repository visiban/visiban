Board templates now have a single source of truth: `GET /api/v1/boards/templates/` and board creation both read the same `BoardTemplate` table, so a template can no longer be listed with different columns than it actually creates. Sending an unknown, explicit `template` slug to `POST /api/v1/boards/` or `POST /api/v1/groups/{id}/boards/` now returns `400` (`{"code": ["unknown_template"], ...}`) instead of silently creating a `simple_kanban` board — omitting `template` still defaults to `simple_kanban` as before. Two templates' column lists (`project_delivery`, `legal_compliance`) and every template's "done" column marking were corrected to match what board creation has actually been producing. Installed packages can now register additional templates via `boards.hooks.TEMPLATE_PROVIDERS`.
