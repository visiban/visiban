The OpenAPI schema now declares the real response body for `GET /api/v1/version/`, `/api/health/liveness/`, `/api/health/readiness/` (including its `503`), `/api/v1/auth/providers/`, `/api/v1/notifications/unread-count/`, `/api/v1/groups/join/{token}/` (which also documents its `404` and `410` now), and the Git Lens board `GET /api/v1/git-lens/board/{board_id}/` (#1647). The parent/child card reads (`.../cards/{id}/children/`, `.../cards/{id}/child-board-options/`, `/boards/{id}/children-setting-blockers/`, `default-child-board-options/` and `delete-impact/`) declare theirs too, and the Git Lens board also documents its `304`, `409`, `502` and `503`. Each of these `200`s previously published no body. The schema also stops listing the `ordering` query parameter on custom actions and `reorder` operations that never read it (#1757). It stays on every list endpoint, which still honors it. No runtime behavior changes.
