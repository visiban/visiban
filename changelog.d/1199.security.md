- Fixed the per-account login lockout (5 failed attempts / 5 minutes) not engaging on `POST /api/v1/auth/login/`, the endpoint the SPA and every API client actually use — it now shares allauth's own rate-limit bookkeeping instead of only being protected by the coarser per-IP throttle, closing a gap that let a distributed attacker (many IPs, one target account) skip the account-level lockout entirely.
