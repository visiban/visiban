The Helm chart's default `backend.resources.limits.memory` is now `1Gi`, up from `512Mi`, because one Analytics drill-down on a 3-year, 12k-card board peaked at 678-720 MB (#2431). Existing installs that do not set `backend.resources` now get the higher limit. To keep the old value, set `backend.resources.limits.memory: 512Mi`. The sizing guidance in the docs now includes the measured figures.
