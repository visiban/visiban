The Helm chart's default `backend.resources.limits.memory` is now `1Gi`, up from `512Mi`, because one Analytics drill-down on a 3-year, 12k-card board peaked at 676-720 MB (#2431). Installs that set `backend.resources.limits.memory` are not affected; an install that sets only part of `backend.resources` still gets `1Gi` for any memory limit it leaves out. To keep the old value, set `backend.resources.limits.memory: 512Mi`. The sizing guidance in the docs now includes the measured figures.
