Helm: a fresh `helm install` with the chart's default values now succeeds. Database migrations moved out of a `pre-install`/`pre-upgrade` hook Job and into a `migrate` init container on the backend Deployment. Helm runs pre-install hooks before it creates any release resource, so on a fresh install the hook tried to reach the bundled PostgreSQL before its StatefulSet and Service existed and the install never returned; `helm upgrade` was unaffected, which is why this survived. Concurrent backend replicas are serialized by a session-scoped PostgreSQL advisory lock (`manage.py migrate_with_lock`), so `backendReplicaCount > 1` remains safe, and a replica that loses the race waits rather than starting against a half-migrated schema. The hook-managed bootstrap Secret is gone with the Job; a `checksum/secret` annotation on the backend pod template now carries `secret.djangoSecretKey` rotations into the same `helm upgrade`. Because the chart no longer declares any install hook, `helm uninstall` removes everything it created. New tunables: `backend.migrate.connectTimeout` and `backend.migrate.lockTimeout`.
