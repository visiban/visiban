Theming: added a design-token layer (`--canvas`, `--surface`, `--text-primary`, `--accent`, etc.) defined as RGB channel triplets on `:root`/`[data-theme="dark"]` and wired into Tailwind so `bg-surface/50` alpha modifiers work. Added a per-user `theme` preference ("system", "dark", "light") stored on the User model and synchronised across devices via `/api/v1/auth/me/`. The picker in Settings exposes System and Dark by default; the Light option is gated behind `VITE_THEME_LIGHT_ENABLED` during the component-sweep rollout (#120). Closes #183.
