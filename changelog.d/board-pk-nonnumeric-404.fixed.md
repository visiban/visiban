Fixed board-scoped API endpoints (boards, columns, swimlanes, labels, cards, custom field definitions, board members, comments, attachments, checklist items) returning a `500` instead of a `404` when a non-numeric id was passed in the URL. Discovered via the CI schema-fuzz job; the underlying models all use plain integer ids, so a garbage id now fails to match the route and 404s cleanly instead of reaching the database layer.
