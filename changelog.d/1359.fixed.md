Fixed the OpenAPI schema for `GET /api/v1/boards/{id}/saved-filters/` and `GET /api/v1/groups/{id}/invite-links/`: both were published as a paginated `{count, offset, page_size, results}` object (with `offset`/`page_size` query parameters) even though they have always returned a plain JSON array of every row. The schema now documents the array the endpoints actually return; runtime responses are unchanged. Clients generated from `/api/schema/` should regenerate.
