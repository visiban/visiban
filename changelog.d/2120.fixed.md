Fixed: a request that declares a non-UTF-8 `charset` such as `utf-7` on its `Content-Type` (for example a query string `?search=%2B2AA-`, or a multipart Trello import) no longer answers a server error on PostgreSQL. Such a request now answers `400 {"detail": "Unsupported request charset. Use UTF-8."}`. UTF-8, US-ASCII, ISO-8859-1, ISO-8859-15, Windows-1252 and UTF-16/32 are still accepted, and an unknown charset is ignored as before. (#2120)
