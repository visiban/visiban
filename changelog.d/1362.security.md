Secret-backed settings (`DJANGO_SECRET_KEY`, OAuth/OIDC client IDs and secrets, `EMAIL_HOST_PASSWORD`, `DEMO_ADMIN_PASSWORD`, `DEMO_MEMBER_PASSWORD`) are now read verbatim, so a value starting with `$` is no longer silently replaced by another environment variable's value.

Installs whose secret starts with `$` now get that literal value instead of an environment-variable substitution.
