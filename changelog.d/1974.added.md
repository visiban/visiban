MCP tool and resource results now carry the stable `uid` on cards, columns, swimlanes, labels and the `board://` snapshot, `card_uid` on the `archive_card` result, plus the column/swimlane `*_uid` snapshots on movements, so an agent can match MCP objects to REST cards, WebSocket frames and change-feed rows. Cards also carry `version`, and `move_card` and `update_card` take an optional `version` argument that rejects a stale write with `version_conflict`; omitting it keeps the previous behavior (#1974).
