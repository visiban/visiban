Add a per-board **default child board** (`default_child_board`, set by an admin of both boards) and **Add child**: `POST .../cards/{id}/children/` creates a child card on another board and links it in one request, and `GET .../child-board-options/` lists where it can go. Deleting a board now records a count-only history entry on each surviving parent ("N children removed: their board was deleted"), clears any default that named it, and `GET /boards/{id}/delete-impact/` and `GET /boards/{id}/children-setting-blockers/` give the delete confirm and the Rules page their warnings (#2208).
