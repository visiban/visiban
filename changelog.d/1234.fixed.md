Fixed missing keyboard-focus indicators on `role="menuitem"` items in the bulk-action toolbar's Move/Assign/Priority menus, the board and lens Collapse/Expand split-button menus, and the board's overflow ("More board actions") menu. These menus already supported full roving-tabindex arrow-key navigation, but a keyboard user arrowing between items saw no visible indicator of which one was focused. All four now carry the same `focus:ring-2 focus:ring-primary-emphasis` ring as `SingleSelectDropdown` and `UserMenu`, sourced from a new shared `MENU_ITEM_FOCUS_RING` constant so the gap can't reappear at a fifth site.
