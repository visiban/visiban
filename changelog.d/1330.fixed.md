Fixed `manage.py benchmark` silently reporting a false "✅ OK" (0 queries) when a restrictive `ALLOWED_HOSTS` rejected the test client's request with `DisallowedHost` before any query ran. The command now scopes `testserver` onto `ALLOWED_HOSTS` for its own requests, and any non-2xx response from an endpoint under test is a hard failure (`CommandError`, non-zero exit) instead of a stderr-only warning.
