Added a `SUPPRESSED-UNTIL(#NNNN)` marker convention for temporary suppressions (`eslint-disable`, `pytest.mark.skip`/`xfail`), a `suppressions-check` CI job (`scripts/check-suppression-issues.sh`) that queries the GitLab API and fails when a cited marker's issue is already closed, and documentation at `docs/development/suppressions.md`. Runs on merge requests, `main`, and scheduled pipelines — not MR-only, since the triggering event is an issue closing rather than a commit landing. Backfilled every previously-unjustified `frontend/src` `eslint-disable` with a permanent reason; audited the backend's `skip`/`skipif`/`xfail` sites and found each already carried an adequate reason (environment gating, no marker needed) (#1092).
