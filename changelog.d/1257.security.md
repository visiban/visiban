- `POST /api/v1/auth/password/change/` now verifies the current password. Previously it changed the password for any authenticated caller — including one holding only a Personal Access Token — without checking the existing one, because dj-rest-auth's `OLD_PASSWORD_FIELD_ENABLED` was left at its default of off. **Integrators:** this endpoint now requires an `old_password` field and returns `400` if it is missing or wrong; update any script that calls it without one. This is a deliberate, security-driven exception to the "new request fields are optional" API rule. Social-only accounts setting their first password may still omit it. `POST /api/v1/auth/change-password/` (used by the web app) is unchanged (#1257).
