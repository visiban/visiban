- MCP tool and resource calls are now rate-limited per personal access token (`MCP_THROTTLE_READ_RATE`, default `300/min`, applied to every call, and `MCP_THROTTLE_COMPUTE_RATE`, default `30/min`, an additional cap on the expensive `list_cards`/`board://{board_id}` reads). Previously `/mcp` had no request throttling at all, since it is mounted in-process and bypasses DRF's throttle classes. A throttled call returns a structured error with a retry hint rather than failing at the transport level.
