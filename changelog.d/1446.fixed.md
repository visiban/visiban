Imported boards are now named consistently: both JSON and CSV imports default to "Imported: <name>" (the board name from a JSON file, or the CSV filename without its extension), adding " - 1", " - 2", and so on when that name is already taken in the target group or among your ungrouped boards. Previously CSV imports were always named "Imported Board". **Behavior change for API callers:** `POST /api/v1/boards/import/` without a `name` field no longer returns a JSON file's board name verbatim — send `name` explicitly to keep a specific name, which is still used exactly as given.
