- The 12-character password minimum is now enforced on every path that sets a password. Django's `MinimumLengthValidator` was running with its default of 8, so self-registration, invite-link registration, the password-reset link, `POST /api/v1/auth/password/change/`, the Django admin and the interactive `createsuperuser`/`changepassword` commands accepted 8-character passwords despite the documented policy. The minimum is now a single `PASSWORD_MIN_LENGTH = 12` setting shared by the validator, `/auth/change-password/` and admin user creation, and the registration and reset-password forms in the web app ask for 12 characters. Existing accounts with shorter passwords are not locked out — the rule applies only when a password is next set (#1258).
