The board Filter panel keeps its header, search box and footer in place while only the field list scrolls, so nothing falls off screen on boards with many fields. A **Filter bar** switch in the panel header replaces the footer's "Show filter bar" / "Hide filter bar (F)" action, the panel's footer now holds **Clear all** and **Save filter**, and Tab stays inside the open panel. The switch, the filter bar's chevron and the Lens **Filters** button all name the toggle the same way ("Show the filter bar (F)" / "Hide the filter bar (F)").
