A WebSocket handshake whose authentication cannot be checked because a server-side store failed is now refused with the reconnectable `1011` instead of `4001` (not authenticated). This covers a cookie handshake during a cache outage with a cache-only session backend (`SESSION_ENGINE=django.contrib.sessions.backends.cache`), and a ticket handshake during a cache or database outage, which previously raised out of the authentication middleware. An absent or expired session, or an invalid ticket, still closes with `4001`. REST requests made with the session cookie during the same outage are still unauthenticated; see `docs/api/websockets.md`.
