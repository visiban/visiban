Added a `compose-hygiene` CI job running two new gates over the shipped Compose files: `check-compose-image-pins.sh` (every third-party image carries an explicit tag; first-party `${APP_VERSION}` references are deliberately out of scope) and `check-compose-project-names.sh` (every standalone Compose file pins a distinct project name, compared on the default inside `${VAR:-…}`, and overlays declare none). Both ship a `--self-test` mode that CI runs before the real invocation, per the house rule in #1093.
