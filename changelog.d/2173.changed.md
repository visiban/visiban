The bulk action toolbar now says why an edit is refused. When none of the selected cards can take Move, Assign, Priority or Archive (for example, cards created by someone else), the button is dimmed and explains the cause instead of failing after the click; when only some can, the rest are skipped and counted with the same reason. The card right-click menu and the command palette use the same wording, and their failures over your whole selection now appear in the toolbar's message area. The "assigning needs a moderator or admin" message is corrected to "you can only assign cards you created".
