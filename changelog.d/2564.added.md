`/wave` now spawns its implementers as the `wave-harness-worker` agent type (`maxTurns: 121`) instead of `general-purpose`, and a new `PreToolUse` hook, `.claude/hooks/pre-tool-agent-budget.sh`, counts every tool call such an implementer makes across all its runs and resumes. Past 120 calls (override: `WAVE_AGENT_TOOL_CAP`) it blocks the call, stops the agent and writes a marker the orchestrator reads with `scripts/wave-agent-budget.py --stopped <agent_id>` before handing off to a fresh agent. Ported from macrodream/blueprint#344 and #352 (#2564).
