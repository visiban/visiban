The "Pin to card face" and "Pin to swimlane row" toggles in the field editor now work when you save an existing field. Before, saving ignored the toggle, so the editor could not unpin a field, pin it again, or pin a different one. When the board is already at its pin limit, saving opens the swap prompt, and that includes saving a new field. Replacing a pinned field from the swap prompt now sends the unpin before the pin and, if either request fails, refreshes the list and says so, instead of silently rolling back to a stale list.
