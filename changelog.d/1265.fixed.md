- Fixed `scripts/release.sh` never updating `docs/index.md`'s release banner for `alpha`/`beta` versions — only `rc.N` and stable releases were handled, so cutting an alpha or beta left `docs.visiban.com` showing the previous cycle's stale banner with no mention of the pre-release. Alpha/beta now get their own banner wording, and the banner-rewrite logic across all three stages now correctly recognizes and replaces each other's banner text, so a release can transition through any stage boundary (alpha → beta, beta → rc, or straight to GA) without leaving two banners in the file.
