Custom field sets: board admins can group a board's card custom fields into named sets (Board Settings → Field sets), each shown on the card detail as its own collapsible block with progress and a Collapsed / Summary / All fields size, plus a Maximize view. Sets can be limited to some swimlanes, reordered, copied from another board, and travel with JSON export and import. New `/api/v1/boards/{id}/field-sets/` endpoints, `custom_field_sets` on `/full/`, a read-only `field_set` on each custom field definition, and `field_set.*` WebSocket events (#2570).
