Issue Board Lens: closed issues no longer crowd open work out of the issue cap. With no state filter the lens loads open issues first and then the 50 most recently updated closed issues; a new **Closed** filter shows none, 20, 50, 100 or all of them, and the provenance banner says when some are not shown. The board endpoint takes an optional `closed_limit` parameter and returns the additive `closed_limit` and `closed_truncated` fields.
The web app defaults to the 50 most recently updated closed issues by sending `closed_limit=50`; the API default is unchanged, so a request without `closed_limit` returns the same issues as before.
