The production Docker Compose nginx template no longer hardcodes a 2-year `Strict-Transport-Security` header for `TLS_MODE=selfsigned` — self-signed installs now send no HSTS header by default, matching the documented behavior. `TLS_MODE=letsencrypt` still sends HSTS by default (the 2-year value is preserved for existing installs that don't set `SECURE_HSTS_SECONDS`), but the header's `max-age` now honors an operator-set `SECURE_HSTS_SECONDS`, which was previously silently ignored. Nginx also now hides Django's own copy of the header on every proxied path (`/api/`, `/admin/`, `/media/`, etc.), so exactly one `Strict-Transport-Security` header is ever sent instead of two. See `docs/administration/upgrade.md` ("Upgrading to 1.2.x") for what this changes on an existing install (#1201).
