Sort swimlanes as a personal view: the new **Lanes** control above the board sorts lanes by name, health, any swimlane field, card count, WIP usage or the sum of a number card field, with a tie-breaker, empty-value placement and pinned lanes. The sort is carried in the board URL, never saved to the server, and never changes the shared board order. The filter strip's lane filter trigger is renamed **Lane filters**.
