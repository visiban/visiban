API: a `multipart/form-data` or `application/x-www-form-urlencoded` request body over one of Django's upload limits (more than 100 file parts or more than 1000 fields, or, for `multipart/form-data` only, more than 2.5 MB of non-file form data; the `DATA_UPLOAD_MAX_*` defaults) now answers a JSON `400 Bad Request` with `{"detail": "..."}`, as the OpenAPI schema documents, instead of an HTML error page.
