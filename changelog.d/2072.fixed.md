API: a `multipart/form-data` or `application/x-www-form-urlencoded` request body over one of Django's upload limits (more than 100 file parts or more than 1000 fields, or, for `multipart/form-data` only, more than 2.5 MB of non-file form data; the `DATA_UPLOAD_MAX_*` defaults) now answers a JSON `400 Bad Request` with `{"detail": "..."}`, as the OpenAPI schema documents, instead of an HTML error page. The limits and the accepted content types are unchanged. A JSON or urlencoded body over 2.5 MB in total, and a query string with more than 1000 parameters, still answer HTML; that follow-up is tracked in #2073 (#2072).
