- Fixed the OpenAPI schema (`/api/schema/`) misdescribing eight fields as `string` (or, for one, with no type at all): `Board.member_count` and `Board.card_count` (actually `integer`), `Board.is_starred` (actually `boolean`), `Board.group_detail` (actually a nested `GroupBrief` object or `null`, now a real schema component), `Board.allowed_priorities` (actually an array of priority values), and `CurrentUser.has_usable_password`, `uploads_enabled`, and `git_lens_enabled` (all actually `boolean`). Schema-only change — no runtime behavior or response body change. A client generated from the schema now gets accurate types for these fields.
