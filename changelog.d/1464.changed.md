Helm: `helm uninstall` now keeps the `<release>-media` PVC, and every uploaded attachment on it (`backend.mediaPersistence.keepOnUninstall`, default `true`, #1464). This changes the behavior of existing installs: before 1.3 an uninstall deleted the PVC. Set `backend.mediaPersistence.keepOnUninstall: false` to keep the old behavior, or delete the PVC by hand with `kubectl delete pvc <release>-media`. See the 1.3 upgrade notes.
