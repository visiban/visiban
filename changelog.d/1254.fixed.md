- Fixed `scripts/release.sh` silently failing to pin the Helm chart's default backend/frontend image tags to the release version — the `sed` anchored on 2-space indentation while `helm/visiban/values.yaml`'s `tag:` lines are 4-space indented, so the chart's default tags had been stuck at `v1.1.0` since before the 1.1.0 GA. The fix scopes the rewrite to only the `tag:` line immediately following a `ghcr.io/visiban/visiban/backend` or `.../frontend` repository line, so the bundled Valkey and `helm test` curl probe image tags at the same indentation are never touched.
