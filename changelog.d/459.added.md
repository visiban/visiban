New **Dwell time** grid overlay: pick it from the **Overlay** menu to see, on the board itself, where work has stopped moving. Each cell shows the median time its visible cards have been in their current column (`4.0d`), with a one-hue tint and a bottom bar on fixed steps (under 1 day, 1 to 3, 3 to 5, 5 to 8, 8 days or more). Done columns and empty cells show nothing. It is computed in the browser, so it follows the filter bar, updates on every move and socket event, and keeps counting while the board stays open. Additive API field: `column_entered_at` (nullable, read-only) on card objects and in the `card.*` WebSocket events, the start of the card's open visit to its column by the *Flow metric definitions* record. Unlike `last_moved_at`, a swimlane-only move does not change it. It is not on the anonymous share-link payload (#459). The value badge of every grid overlay is now an opaque pill, so a value stays legible where it crosses the first card's border, and a selected or focused card lifts above it.
