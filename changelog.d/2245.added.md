Automatic health status (#2245): a board admin can turn on **Calculate health status automatically** in Board Settings. Each night (the `compute_health_status` scheduled job, `SCHEDULE_COMPUTE_HEALTH`, default 02:00 UTC) every lane is rated from its open cards: 1 or more overdue, stale or blocked cards is At risk, and a per-board absolute count (default 3) is Off track. The board shows the worst lane. This reverses the 1.3 lane status rule that a lane never rolls up to the board, on auto boards only. A status set by hand is a pin that always wins, and the calculated value stays visible beside it. Board admins can run **Recompute now**; installs without the scheduler show "Never computed". New API fields on boards and swimlanes, and `POST /api/v1/boards/{id}/health-recompute/`.
