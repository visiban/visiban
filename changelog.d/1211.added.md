Helm: the bundled Valkey can now require a password. Set `valkey.auth.enabled=true` with either `valkey.auth.password` or `valkey.auth.existingSecret` (plus `existingSecretPasswordKey`). The password reaches Valkey and the backend only through that Secret, never through a ConfigMap or a plain environment value, and it can contain any character, including `/` and `@`. Auth stays off by default, so existing installs are unchanged on upgrade. Before this change, `valkey.auth.enabled=true` was refused at render time because it never produced a working deploy. See [Valkey password](docs/getting-started/kubernetes.md#valkey-password) (#1211).
