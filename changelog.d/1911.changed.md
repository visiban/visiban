Helm: chart 0.8.0 removes the opt-in Bitnami PostgreSQL subchart. `postgresql.subchartEnabled=true` never rendered with the chart's values (the subchart needs an image map where `postgresql.image` is a string), and Bitnami no longer publishes versioned tags for its images; it now fails the render with migration steps instead. The default bundled PostgreSQL StatefulSet, an explicit `postgresql.subchartEnabled: false`, and external databases are unchanged. The chart no longer ships a vendored subchart, so `helm dependency update` is not needed. See "Helm: the Bitnami PostgreSQL subchart is removed" in the upgrade guide (#1911).
