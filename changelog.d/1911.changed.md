Helm: chart 0.8.0 removes the opt-in Bitnami PostgreSQL subchart. `postgresql.subchartEnabled=true` never rendered with the chart's default values (the subchart needs an image map where `postgresql.image` is a string; only 1.0 and 1.1 values files that replaced it with a Bitnami map or set it to `null` could render it), and Bitnami no longer publishes versioned tags for its images; it now fails the render, before anything is applied, and the upgrade guide gives a verified dump-and-restore path. An empty or `null` `postgresql.image` now also fails the render instead of producing a StatefulSet with an empty image. The PostgreSQL major-version procedure in the deployment guide now stops writers, verifies the dump, and restores into an empty database in a single transaction (`psql -1 -v ON_ERROR_STOP=1`) before starting the backend. The default bundled PostgreSQL StatefulSet, an explicit `postgresql.subchartEnabled: false`, and external databases are unchanged. The chart no longer ships a vendored subchart, so `helm dependency update` is not needed. See "Helm: the Bitnami PostgreSQL subchart is removed" in the upgrade guide (#1911).
