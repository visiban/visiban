Dimension chips on the card face: a board admin can pin up to 3 dimension fields (a separate pool from the 2 pinned fields), shown as state chips with an icon and spelled-out state, plus an "N need attention" count for open dimensions past their target date. Each dimension on a card can carry a plan (owner, next action, optional target date) through `PUT /api/v1/boards/{board_id}/cards/{id}/dimension-plans/{field_id}/`, returned as the new read-only `dimension_plans` card field and broadcast as `card.updated` (#1922).
