Hardened the invite-join and public-share client calls: board and group join tokens are allowlist-validated (`[A-Za-z0-9_-]`, 1-256 chars) and share tokens must be UUIDs before being placed in the request path, so a crafted token such as `..` can no longer redirect the request to a different endpoint. The SSRF egress deny-list address literals are recorded as a reviewed Sonar false positive.
