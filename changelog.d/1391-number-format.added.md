Number custom fields gain optional, display-only **number formatting**, for both card and swimlane fields: a **Prefix** and **Suffix** (up to 10 characters each, spaces kept — e.g. `$` or ` h`) and a fixed number of **Decimals** (0–10, with thousands grouping), set in a new **Format** block with a live preview in Board Settings. Values show formatted on the card face, card detail, hover peek and swimlane row chips (`$1,234.50`, `-$5.00`); the value editor keeps a plain number box with the prefix and suffix shown beside it. The stored value is unchanged — still the raw number string on the wire, in CSV and JSON exports, and in filters. The API change is additive: `number_prefix`, `number_suffix` (default `""`) and `number_decimals` (default `null`) on both custom field definition endpoints, their WebSocket events, and the JSON export's field schema (migration `0065`, nullable/defaulted columns only). Setting any of them on a non-number field is a `400`, and retyping a field away from number clears them (#1391).
