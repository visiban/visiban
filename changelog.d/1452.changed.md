The sample board JSON files moved from `sample-boards/` to `backend/boards/sample_boards/`, so the backend image now ships them. Raw links to `sample-boards/<name>.json` (including the `curl` examples in the docs) no longer work; use `backend/boards/sample_boards/<name>.json`. The CSV files and `demo_board.json` stay in `sample-boards/`. A new `manifest.json` next to the JSON files lists every sample (id, title, swimlane theme, active card count, included features, display order, checksum) and is the single source for the docs tables. The sample files are now named without the "Template:" prefix, so an import is named "Imported: Sales Pipeline". `seed_template_boards --export` is retired and refuses to run: `backend/boards/seed_data/generate_seed_data.py` is the only writer of the sample files (#1452, #1450).
