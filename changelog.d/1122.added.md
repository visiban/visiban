Number and date card custom fields can mark values that cross a threshold. Set **Above** or **Below** with a warning and an alert value (days from today for dates) under Board settings → Card fields → Thresholds. A marked value shows a chevron and bold text on the card, never a color, with the threshold in words in the hover peek, the card detail panel and for screen readers. The API adds five optional, stable fields to card custom field definitions (`threshold_direction`, `threshold_warn`, `threshold_alert`, `threshold_warn_days`, `threshold_alert_days`), carried in the JSON export and import.
