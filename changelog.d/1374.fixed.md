Failed actions on the Dashboard, Admin, Settings, and Group pages now surface an error message instead of failing silently: a failed initial board/group load on the Dashboard, a failed board delete (which now also reconciles the list with the server instead of leaving the board permanently missing), a failed clipboard copy of an admin invite link, and a failed load of personal access tokens in Settings. Fixed 31 floating promises across `frontend/src/pages` (`typescript:S9383`) — navigation calls and other self-handled async calls are now explicitly marked fire-and-forget with `void` (#1374).
