The experimental issue board lens gained a **pipeline** column view that derives a Backlog → To Do → Doing → Review → Done workflow from repository state: an issue moves to Doing when a feature branch for it exists, to Review when an open merge/pull request references or closes it, and to Done when it's closed. Each card shows the branch name or MR that placed it there. Branches and MRs are only fetched for the pipeline view (GitLab anonymous, gitlab.com public projects), bounded by the lens's shared cache.
