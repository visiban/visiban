- Fixed the OpenAPI schema (`/api/schema/`) understating nullability on `Card.created_by`, which is documented as always a `BoardUser` object even though the underlying FK is `SET_NULL` and returns `null` once the creating user is deleted. `CardSerializer.created_by` now declares `allow_null=True` so the published schema matches the real response shape. A client generated from the schema no longer needs to guard against an undocumented `null`.
