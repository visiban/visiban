Card `activities/`, `comments/` and `attachments/` lists accept optional `limit`/`offset` query parameters and send `X-Total-Count`/`X-Truncated` headers, so a client can bound the read on a long-lived card. Without the parameters the response is unchanged: every row, as a bare array. The MCP `card://` resource now returns at most the 200 newest activities and comments, with additive `activities_truncated`/`comments_truncated` flags. (#1963)
