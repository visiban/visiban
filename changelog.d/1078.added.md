Added a `ws-event-reachability` CI gate that reconciles every WebSocket event name across the three places it lives — emitted, documented, and handled — so a name present in only two of them can no longer look complete. The emitted set is now declared as a registry in `boards/broadcast.py` and `groups/broadcast.py` that every broadcast call site draws from; a bare string literal at an emit site fails the gate. Documented `lens_connection.configured`, `lens_connection.removed`, the group channel's `member.removed`, and `invite_link.revoked`, which were emitted and handled but missing from the WebSocket API reference. No wire format changed.
