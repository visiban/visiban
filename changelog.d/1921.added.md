Gated stages (#1102, phase 1 backend) and dimension fields (#1921): a column can hold 2-4 sub-columns, and a card's `gates_passed` records which one it is in. The move endpoint and MCP `move_card` take an optional `gates_passed`, each gate passed or reopened is recorded, and movements record gates left open. Board admins save sub-columns, tracks and lane not-applicable marks with `PUT .../columns/{id}/stage/`. Dropdown fields can be dimensions whose choices resolve to open, done or not applicable, and every custom field value change now appears in card history.
