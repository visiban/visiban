**Maintenance mode** — site admins can now put the instance into read-only mode from Admin → Settings, for upgrades and migrations. While it is active, every non-admin write is rejected with `503 Service Unavailable` and a `maintenance_mode` error code, reads keep working, and all users see a configurable notice. Site admins are exempt and keep full read/write access. The setting is stored in the database, so it survives a restart, and takes effect immediately without one. Disabled by default — an existing install is unaffected until an operator turns it on.
