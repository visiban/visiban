- Fixed the scheduled `main` pipeline going red on `dockerfile-lint`. The job ran `hadolint/hadolint:latest-alpine`, which floated into hadolint 2.15 and introduced `DL3066` (non-numeric user-id in `USER`) — turning a green job red with no Dockerfile change. The image tag is now pinned to `v2.15.1-alpine`, and `DL3066` is ignored in `.hadolint.yaml`: both backend Dockerfiles create the runtime user with an explicit fixed uid (`adduser --uid 1001`), so `USER visiban` always resolves to 1001 inside the image.
