Valkey now has a memory ceiling and a `volatile-lru` eviction policy in the dev and production Compose files and the Helm chart (`valkey.primary.maxmemory`, `valkey.primary.maxmemoryPolicy`; production Compose reads `VALKEY_MAXMEMORY`), so a busy instance evicts old cache entries instead of growing until the container is OOM-killed. See Administration > Configuration.
