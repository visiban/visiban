Keyboard shortcut coverage audit: view tabs now have `b` / `s` / `h` / `a` bindings, `e` toggles collapse of everything, `y` toggles the archived cards panel, and `⌘⇧L` / `Ctrl+Shift+L` switches between the compact and expanded card layouts. The `/` shortcut for focusing the search box is now a visible chip inside the filter bar's search input. The shortcuts overlay has been regrouped into four sections (Navigation · Board view · Board actions · Help) with imperative-tone descriptions, widened key column for longer chords, and platform-aware glyph rendering. Every single-key and single-modifier binding is announced through `aria-keyshortcuts` for screen readers; two-modifier chords stay in the overlay only. Bare-letter shortcuts continue to be suppressed while typing in inputs, textareas, and rich-text editors. New doc: Features → Keyboard Shortcuts.
