Added `scripts/check-chart-registry.sh` and two CI hooks (#1155): a scheduled `check-chart-registry` job that verifies a bare `helm install oci://ghcr.io/visiban/charts/visiban` resolves to a chart whose default images exist (only a `404` counts as a missing image; an unreadable registry fails the job without suggesting a deletion), and a publish guard in `helm-publish` that refuses a stable chart version from a pre-release tag, a chart version that is already published, and a pre-release chart version whose plain stable version is already published. Pre-release tags now publish the chart as `<chart version>-<pre-release>` (for example `0.8.0-beta.1` for `v1.3.0-beta.1`) instead of the plain chart version, so install a pre-release chart with `--version` (or `--devel`).
