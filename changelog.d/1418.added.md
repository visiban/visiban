Board admins can hide field names on pinned swimlane row chips, so each chip shows its value alone (for example `Diane Foster` instead of `AD: Diane Foster`). Turn off **Show field names on row chips** in Board Settings → Swimlane fields. The name stays in the chip's tooltip and for screen readers, and in the row's field list when the row has one. Checkbox fields always show their name, and card-face chips are unchanged.
