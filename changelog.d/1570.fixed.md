The schema-fuzz CI job now reaches the group, join-token, share-token, media, card-relation and card-collection routes it previously reported as repeatedly returning 404, and its authorship-gated DELETE operations use rows the fuzz user owns (#1570).
Deleting a group as a member who is not its owner now returns a JSON error body with the 403, and a checklist reorder request whose JSON body is not an object returns 400 instead of 500 (#1570).
Moving a card with a `position` outside the database integer range no longer fails with a server error: the position is clamped into the target cell (a negative value places the card first, a value past the end places it last), and a non-integer `position` returns 400 (#1570).
