Custom-field choices can now take a custom hex color as well as the eight preset colors: **+ Custom** in the choice color popover opens the color square, hue slider and hex/R/G/B fields, and the API `choice_colors` map accepts `#RRGGBB` (stored upper-case). Presets keep rendering unchanged. A board export that uses a custom choice color is refused, as a whole, by servers older than 1.3. (#2096)
