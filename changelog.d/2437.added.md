The Filter panel now searches field names and values across card and swimlane fields. It is wider (520px), has All fields / Card fields / Swimlane fields chips, lists matching values with counts and a "Title contains" fallback, accepts `field:value` shorthand, and Esc clears the search before closing. A swimlane field set to Hidden on the band stays searchable, marked "(hidden on band)", and admin-only fields stay hidden from non-admins. (#2437)
