Closed a duplicate-account path in OAuth signup: when a provider's email collided with an existing account, or returned no email at all, the flow used to fall through to allauth's own unstyled signup form with the email pre-filled in an editable field — letting it be changed to create a second account for the same OAuth identity. `GET /accounts/3rdparty/signup/` is now intercepted and redirects to the frontend with `?auth_error=oauth_failed` instead.
