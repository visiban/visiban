Site admins can set a personal access token lifetime policy under Site admin → General → Personal access tokens: a maximum lifetime (when set, every new token must expire within that many days, and a token with no expiry is refused) and a default expiry that the token form pre-fills. Both are unset by default, so existing installs behave as before, and existing tokens keep their expiry. The policy is in `GET`/`PATCH /api/v1/admin/settings/` (`pat_max_lifetime_days`, `pat_default_lifetime_days`), changes are recorded in the action log, and `GET /api/v1/auth/tokens/policy/` serves it to the token form (#1572).
