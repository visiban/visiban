MCP server: added the full set of OSS CRUD tools for AI agents — `list_columns`, `list_swimlanes`, and `list_cards` (filterable by column, swimlane, assignee, priority, and label) for reading board state, and `create_card`, `move_card`, `update_card`, and `archive_card` for writing it. Write tools require an admin or member board role and now additionally require the token to carry the `mcp:write` scope (previously documented as reserved but unenforced, since no write tool existed yet), so an `mcp:read`-only agent credential stays read-only. Every write reuses the same service functions, WIP/weight enforcement, `CardMovement` audit trail, and WebSocket broadcast as the REST API — a blocked move returns a structured error (e.g. `wip_limit_exceeded`) rather than an exception. Agents identify people by email and labels by name; an unresolvable email or label name returns a structured `validation_error` (#512).
