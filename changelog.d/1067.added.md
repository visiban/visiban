The Issue Board Lens filter row gains **label** and **assignee** filters, and an explicit **(no milestone)** option in the milestone control. Like the existing state and milestone filters, both new filters are applied at the provider rather than in the browser, so they reach issues that fall outside the 300-issue fetch cap — filtering to a label is now a way to see *more* work, not less. Labels combine with "and" (an issue must carry every selected label) and up to five can be selected at once. GitHub milestone filtering also moved server-side: it previously ran in the browser over the already-fetched page, which silently dropped matching issues beyond the cap (#1067).
