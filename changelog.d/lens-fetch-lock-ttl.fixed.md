Fixed the issue board lens's single-flight fetch lock expiring mid-fetch on the Pipeline view. The lock is what stops several viewers all calling the provider at once, and it was sized for the issue pages alone (45s) while a Pipeline fetch also pages through branches and merge requests — up to 70s. Under a slow provider the lock could lapse while a fetch was still running and let a second viewer start another one. Now sized to the real worst case. This surfaces more often since new lenses default to the Pipeline view.
