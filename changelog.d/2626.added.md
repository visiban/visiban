Backups and a tested restore for self-hosted installs (#2626, #1464). `scripts/backup.sh` writes a plain-SQL database dump plus a media archive, with retention, and fails (keeping nothing) on a failed, empty or truncated dump; `scripts/restore.sh` restores a set onto a fresh install in one transaction. Docker Compose gains an opt-in daily `backup` profile, and the Helm chart an opt-in backup CronJob writing to a PVC (`backup.enabled`). The Helm media PVC is now kept on `helm uninstall` (`backend.mediaPersistence.keepOnUninstall`, default `true`). CI backs up a seeded Compose install, restores it into a fresh one and checks that boards, cards, movements and attachments survive. See the new "Back up and restore" administration page.
