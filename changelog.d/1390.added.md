Custom fields gain a **URL** type, for both card and swimlane fields. Values must be absolute `http://` or `https://` addresses (the web UI adds `https://` to a bare domain; the API rejects `javascript:`, `data:`, and every other scheme with a `400`) and, like every custom field value, at most 500 characters. Values render as links that open in a new tab — the full address in the card detail panel, the hostname on pinned card-face and swimlane-row chips — and URL fields filter by substring. The API change is additive: `field_type` accepts the new value `"url"` (migration `0063` is a no-op at the database level), the TypeScript `CustomFieldType` union gains `"url"`, and enterprise `CUSTOM_FIELD_VALIDATORS` hooks may now see `field_type="url"`. Clients that do not know the type should render the value as plain text (#1390).
