- Docker Compose host ports are now overridable via `.env` (`DB_PORT`, `BACKEND_PORT`, `FRONTEND_PORT`, `KEYCLOAK_PORT`, `REDIS_PORT`) and the project name via `COMPOSE_PROJECT_NAME`, so a second Visiban checkout (or another project sharing the same default ports) can run side-by-side on one host without colliding. Vite's HMR client port follows `FRONTEND_PORT` automatically when the host port is remapped.
