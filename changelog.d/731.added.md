Group admins and site admins can now email an invite link straight to someone's address instead of copying it: an "Invite by email" section in the group's Invite links panel and in Site Admin → Invite Links sends a single-use link that expires in 7 days, shows an "Emailed" badge in the list, doesn't count against the shareable-link limits, and is revoked automatically if the mail server rejects the message. Operators can turn the feature off with `INVITE_EMAIL_ENABLED=false` (#731).
