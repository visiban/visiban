Board presets: pick **Classic** or **Default** from the new **Preset** dropdown in the board toolbar to set card density and the grid overlay in one step, with a **Modified** tag, **Reset**, and **Undo**. A `?preset=` link applies a preset, board admins can set a default preset in **Board Settings → Display**, and the board API gains a nullable `default_preset` field. **Classic** keeps the board exactly as it looked before presets, and boards with no default preset are unchanged (#1146).
