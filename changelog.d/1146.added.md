Board presets: pick **Classic** or **Default** from the new **Preset** dropdown in the board toolbar, or with **Apply preset** in the ⌘K command palette, to set card density and the grid overlay in one step, with a **Modified** tag, **Reset**, and an **Undo** notice. A `?preset=` link applies a preset, board admins can set a default preset in **Board Settings → Display**, and the board API gains a nullable `default_preset` field. **Classic** keeps the board exactly as it looked before presets, boards with no default preset are unchanged, and a personal density or overlay set before 1.3 is never shown as a preset (#1146).
