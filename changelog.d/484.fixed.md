Dashboard, group page, and notification dropdown now follow the design system (#484, #487): a failed boards or groups load shows an error with a Retry button that keeps keyboard focus while it retries, instead of the onboarding screen; section empty states use the shared centered-icon pattern and are hidden below the onboarding state; group page errors and the "Saved" confirmation appear in reserved, screen-reader-announced slots that no longer shift the layout; the notification dropdown uses the engraved separators; light-mode primary buttons now darken on hover instead of lightening; and every Cancel button uses the standard secondary style with a hover background.
