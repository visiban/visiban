Notification retention: new `prune_notifications` management command deletes in-app notifications, read or unread, older than `NOTIFICATION_RETENTION_DAYS` (new env var, default 90 days, minimum 14). It supports `--days`, `--batch-size` and `--dry-run`. It runs only when scheduled, and the shipped scheduler leaves it off, so existing installs keep every notification until an operator enables it. The 14-day floor exists because notification rows are also the de-duplication record for the scheduled notification scans.
