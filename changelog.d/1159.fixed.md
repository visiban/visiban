Fixed the "Also send by email" notification switch being unreachable by keyboard when its parent notification is off. `Toggle` previously used the native `disabled` attribute for this state, which removes a control from the tab order — the reason it's off was announced only in screen-reader browse mode. `Toggle` now supports an opt-in `ariaDisabled` prop: the switch stays focusable, click and keyboard (Space/Enter) activation are both ignored, and the same disabled visual styling is kept. The email notification switches now use it; plain `disabled` is unchanged everywhere else (#1159).
