`ensure_site_admin` now creates the one-time admin password file with `O_EXCL` (in addition to `O_NOFOLLOW` and mode 0600), so a file pre-created by another local user in a shared directory such as `/tmp` is never reused. A stale file owned by the same user is replaced; anything else (symlink, another user's file) is left untouched and the password is printed to the command's stdout instead. The default path and `VISIBAN_ADMIN_PASSWORD_FILE` are unchanged. The same exclusive-create write now protects the schema-fuzz token file written by `provision_fuzz_token`, which fails with an error instead of falling back to stdout when the path is a foreign-owned or non-regular file.
