The group page now uses the shared Overview layout, with the breadcrumb Home / group in the header, a Members column visible to everyone in the group, and the admin-only sections moved into a Group settings view (Members, Invite links, Health status review, Board defaults, Shared labels, Danger zone) at `?tab=settings`. Deleting a group now asks you to type its name, and the deprecated "Allowed priorities" control is no longer shown. Transferring ownership now happens in place in the Danger zone instead of a dialog, group invite links use the same layout as Site admin, the Members list collapses behind a button on phones, and the header shows who last set the status and when.
