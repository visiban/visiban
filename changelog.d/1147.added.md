Added a generic **grid overlay slot** to the board view: a pluggable layer that shades each board cell from a per-cell number without changing the grid's layout. An overlay supplies only a value and a label per cell; the slot owns the scale, the tint, the legend, and the empty state — including the accessibility contract, so every step is encoded three ways (tint, the height of a bar on the cell's bottom edge, and the value itself) and no overlay can ship a color-only ramp (#969). Two overlays ship: **None** (the default — the board renders exactly as before) and **Card count**, a reference overlay computed from the cards already loaded, adding no queries. Pick one from the **Overlay** dropdown in the board toolbar; the choice is remembered per board (#1147).
