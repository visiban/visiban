**Helm:** `backend.email.backend` now defaults to `""` (unset) instead of `"smtp"`. Setting `EMAIL_BACKEND` pins the mail backend and disables the new Admin → Settings → Email UI, so the chart no longer emits it unless you configure it explicitly. The chart's render-time check for a placeholder `fromAddress` now fires only when `backend.email.host` is set, so you can install first and configure email from the admin UI afterwards. Set `backend.email.backend` explicitly to keep env-only behavior. Also adds `backend.email.useSsl`.
