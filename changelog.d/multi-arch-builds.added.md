Added multi-arch Docker image builds (AMD64 + ARM64) to CI. Per-arch kaniko jobs push arch-suffixed tags; a `crane index append` manifest job merges them into a single OCI image index so `docker pull` works natively on both architectures. ARM64 jobs are gated behind the `ENABLE_ARM64_BUILD=true` CI variable and `allow_failure: true` until an ARM64 runner is registered. Manual GHCR push jobs are also split into per-arch + manifest steps.
