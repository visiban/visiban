The board JSON export's `deleted_card_history` entries now carry the deleted card's retained block and gate transition records (`blocks`, `gate_transitions`), and JSON import restores them on the new board with the history option, attributed to the importer with the original name kept. With history off they are counted in the new `import_summary.skipped.blocks` and `gate_transitions` keys, which also count live cards' block and gate history.
