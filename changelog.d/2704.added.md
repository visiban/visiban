Dimension plans (owner, next action, target date) now travel with the JSON board export and are restored on JSON import, with owners matched like card assignees (an unmatched owner imports as Unassigned). A new MCP write tool, `set_dimension_plan`, sets a card's plan for one dimension, named by field name with the owner as a username, and every card in MCP tool and resource output (not the compact `aging_cards` rows) now carries its plans as `dimension_plans`. A shifted import (`shift_dates_from` or a sample's `date_anchor`) moves plan target dates and dimension change times with the rest of the board. CSV and board templates do not carry plans. (#2704)
