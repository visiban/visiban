**Behavior change for API callers:** a JSON board import (`POST /api/v1/boards/import/`) sent without a `name` field now names the board "Imported: <name from the file>", numbered " - 1", " - 2", and so on on duplicates, instead of using the file's name verbatim. Send `name` explicitly to choose the name; it is still used exactly as given. See the 1.2 upgrade notes.
