Analytics: the flow row's final "finished" connector no longer counts a card twice when it moves from one done column to another, or again when a reopened card finishes. It now reads a new additive `completed` / `completed_per_week` pair on the cumulative-flow endpoint, built from first completions as throughput defines them. Connector rates are labeled "avg / wk" so they are not mistaken for the Throughput tile's weekly median.
