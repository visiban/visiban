Boards whose cards can have children can now name those parent cards (for example "Initiative" / "Initiatives") in Board settings > Rules; the name labels the parent row on linked child cards and the parent picker. Also adds an experimental, read-only card-detail extension slot (`CARD_DETAIL_EXTENSIONS`, `GET /api/v1/boards/{b}/cards/{c}/extensions/`) so an installed extension can show its own section in a card's Details tab (#2212).
