The card detail panel now has three tabs, **Details**, **Comments** and **History**, replacing Details and Activity (#967). Comments and History show their counts in the tab ("Comments 4"), the panel opens on the tab you chose last this session (a `?card=…&tab=comments` link overrides it), the tabs support Left/Right/Home/End, and Details ends with a "Last activity" line that jumps to History. The History filter is now six toggle buttons, one per event type with its count, all on by default, and at least one stays on; it replaces the filter menu, whose default was column moves only. A **Show full history** choice saved by earlier versions is ignored. The card timeline API (`GET /cards/{id}/timeline/`) takes an optional `include_counts=true` that adds a per-group `counts` object.
