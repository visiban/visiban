Both board imports now return the same envelope: `POST /api/v1/boards/import/` also returns `board` and `summary`, and the Trello import's confirm response also returns the board's fields at the top level and `import_summary`. No field was removed. Every error from the two import endpoints now carries a stable `code` next to `detail` (for example `no_file`, `file_too_large`, `invalid_file`, `limit_exceeded`, `invalid_options`); see the API docs for the list.
