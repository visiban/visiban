- Fixed the OpenAPI schema for `GET /api/v1/boards/{id}/full/`. It was documented as the plain `Board` shape, so its `members` rows, which can carry `id: null` (group-inherited members, the board owner, site admins) and `role: "site_admin"`, did not match any published schema. `/full/` is now documented as its own `BoardFull` component, and its `members` items as a new `EffectiveBoardMember` component that allows both. The response body is unchanged, and the strict `BoardMembership` component returned by `POST /boards/{id}/members/` is unchanged too. Every existing component and enum name is preserved, and the only additions are `BoardFull`, `EffectiveBoardMember` and `EffectiveBoardRoleEnum`.
