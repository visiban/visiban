Replaced the `psycopg2-binary` PostgreSQL driver (maintenance-mode upstream) with `psycopg[binary]` 3.3.6 (psycopg 3). No settings, env vars, or `DATABASE_URL` values change: Django 5's `django.db.backends.postgresql` backend selects psycopg 3 automatically. Docker and Helm installs pick this up by pulling the new image. Operators running from source must reinstall `backend/requirements.txt` (or `requirements.lock`) in their virtualenv, because `psycopg2` is no longer installed (#1252).
