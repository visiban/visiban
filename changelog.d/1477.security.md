Realtime: a user removed from a board or group no longer keeps receiving its WebSocket events when the `member.removed` event that closes their connection is lost to a channel-layer error. Board and group connections now re-check access before they forward each event. The check uses the same rule as the connection handshake and is cached for 5 seconds per connection. A connection that has lost access, including one for a deactivated account, is closed with code `4003`. A role change that sends no `member.*` event on the board channel, such as a group role change, now takes effect within 5 seconds instead of on reconnect.
