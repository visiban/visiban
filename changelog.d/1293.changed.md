**Behavior change:** `POST /api/v1/auth/registration/verify-email/` now returns `409 Conflict` with `code: "email_in_use"` when the key is valid but another account has already verified the address. Previously it returned `200 {"detail": "ok"}` without confirming anything. This applies to email-change and signup confirmations alike. The SPA's confirmation page now explains that the address is already in use. (#1293)
