`migration-check`, `backend-schema-validate`, `backend-schema-fuzz`, and `oidc-smoke` no longer run unconditionally on every merge to `main` — they now run only when a merge's own diff touches the paths their `changes:` rule already scopes (same as on the MR pipeline). A docs-only or frontend-only merge previously still paid for a full DB migration cycle, OpenAPI schema validation, up to 600s of schemathesis fuzzing, and a Keycloak boot, none of which could have been affected. Jobs that gate the image-publish path (`backend-test`, `backend-test-coverage`, `frontend-test`, and friends) are unchanged (#1266).
