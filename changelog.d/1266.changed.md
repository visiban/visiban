17 CI jobs — `migration-check`, `backend-schema-validate`, `backend-schema-fuzz`, `oidc-smoke`, `helm-lint`, `helm-template`, `backend-lint`, `broadcast-deferral`, `compose-hygiene`, `dockerfile-lint`, `frontend-lint`, `gate-selftest-parity`, `playwright-e2e`, `rbac-coverage`, `serializer-ts-parity`, `shellcheck`, and `ws-event-reachability` — no longer run unconditionally on every merge to `main`. Each now runs only when a merge's own diff touches the paths its `changes:` rule already scopes on the MR pipeline. A docs-only merge previously still paid for a full DB migration cycle, OpenAPI schema validation, up to 600s of schemathesis fuzzing, a Keycloak boot, a full Helm chart lint/template/kubeconform pass, and a Playwright browser install, none of which could have been affected. Jobs that gate the image-publish path (`backend-test`, `backend-test-coverage`, `frontend-test`, and friends) are unchanged; so is `trivy-scan`, whose unconditional main run also catches CVEs newly disclosed against an unchanged pinned dependency (#1266).
