# Control who can see and change what

<a id="roles-access-control"></a>

Assign one of five roles at the group or board level; see the guides below.

**Why it matters:** Roles determine who can restructure a board versus who can only view it.

**The big picture:** Visiban uses role-based access control (RBAC) at both the group and board level.

| Guide | Description |
|---|---|
| [Roles & Permissions](roles.md) | The five roles (site_admin, admin, member, collaborator, viewer) and the full permission table |
| [Role Inheritance](inheritance.md) | How group membership cascades down to boards and subgroups |
| [Managing Roles](managing.md) | How to assign, change, and revoke roles via the UI or API |

Looking for board-level detail — exact minimum role per card/comment/attachment action, and the moderator entitlement? See [Board Role Permissions](../permissions.md).
